# بوابة دروس قسم اللغة العربية — ثانوية طلحة بن عبيد الله

صفحةٌ واحدة تقود المعلّم إلى عرضه: **المرحلة ← المعلّم ← التناول**، ومع كل تناولٍ ورقةُ تحضيره.

| الصف | الدروس |
|---|---|
| العاشر | مرثية أبي ذؤيب · بلاد الهولو |
| الحادي عشر | خديجة بنت خويلد · وقفة على السّور |
| الثاني عشر | اللغة والدين والعادات · مَن يعدل الأذناب بالذُّرا؟ |

## أدوات الشرح في كل عرض
- **القلم**: ثلاثة ألوان وثلاثة أحجام، مع ممحاة وتراجع (Ctrl+Z) ومسح الصفحة؛ ولكل شريحة رسمها.
- **الليزر**: خطٌّ أحمر يُمسح بعد رفع القلم بثلاث ثوانٍ.
- **السبّورة**: صفحاتٌ خالية للشرح بالقلم، و«العودة إلى الشريحة» أو Esc للرجوع.
- **مؤقّت ٩٠ ثانية**: للكتابة، وحين ينتهي ينتقل العرض إلى الشريحة التالية وحده.
- **الروليت**: يختار طالباً من فصول المعلّم.

## البنية
- `index.html` البوابة
- `d/<الدرس>/NN.html` عرض التناول، ويأخذ اسم المعلّم من `?t=` وفصوله من `d/rosters.js`
- `p/<الدرس>/<المعلّم>/NN.pdf` أوراق التحضير
- `x/` موادّ أخرى
